Bokkie

The lending system for TLS Palay & Corn Buying Station. This page is for the person installing it on the station’s computer.

Download Bokkie for Windows One file. Windows 10 or later, 64-bit.

Version — see latest.json · SHA-256 — see latest.json

There is no public release yet

The first release is built and signed, and is being checked on Windows before it is published. The download button will work as soon as that finishes — there is nothing to do here but come back.

If you need it today, ask the developer for the release folder on a USB stick.

Windows will warn you about this file

When you run it you will see a blue box saying “Windows protected your PC”. This is expected. It appears because the file is not signed by a certificate this project has paid for — not because anything is wrong with it.

  1. Click More info.
  2. Click Run anyway.

If you would rather check the file than take that on trust, the SHA-256 above is published inside the signed latest.json. In PowerShell: Get-FileHash BokkieSetup.exe

What happens when you run it

  1. A black window opens and asks what you want to do. Choose Start Bokkie here by typing its number and pressing Enter.
  2. A second window opens showing that Bokkie is running, the address the counter computers use, and when it last backed up.
  3. Windows may ask whether to allow Bokkie on the network. Say yes.
  4. Open http://bokkie.local:8080 on a counter computer, or press Open Bokkie on the window.

Bokkie runs only while that window is open

Closing the window stops Bokkie, and the counter computers lose it until somebody opens it again. Nothing is deleted — a backup is taken on the way out.

It does not start by itself. After a power cut, a restart, or a Windows update, somebody has to open it again. That is deliberate: Bokkie is open when a person has opened it and at no other time.

Bokkie starts with the computer from then on. Nobody needs to be logged in for the other computers at the station to reach it.

On the counter computers

Run the same file on each counter PC and choose Put a Bokkie shortcut on this computer’s desktop. That needs no administrator password and installs nothing — it only puts an icon on the desktop that opens Bokkie.

If the station has no internet

Everything above needs a connection once, to download one file. If the station has none, download it on a computer that does and copy it across on a USB stick:

BokkieSetup.exe

The same one file. Copy it to the host computer and double-click it — there is nothing else to run and nothing to install.
