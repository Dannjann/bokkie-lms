# Step 2.6 Implementation Plan — One File From the Internet

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `BokkieSetup.exe` — one downloaded file — install, update, repair,
shortcut and uninstall bokkie on a Windows 10 station, and publish it from a
download page that names its own version.

**Architecture:** The setup exe *is* `bokkie-win-amd64.exe` under a friendlier
name. A no-argument launch that owns its console (Explorer, not `cmd`) runs a
guided menu instead of printing usage; everything careful underneath is the
`internal/service` install that already exists. Windows-only syscall plumbing is
kept to thin wrappers in `internal/winsetup`, and every decision those wrappers
feed is a pure function in an untagged file — because the only Windows machine
this project has is a CI runner.

**Tech Stack:** Go 1.27, `CGO_ENABLED=0`, `golang.org/x/sys/windows` (already in
`go.sum` as indirect), PowerShell for the `.lnk`, GitHub Actions
`windows-latest`, static HTML on GitHub Pages.

**Spec:** [02.6-github-distribution.md](02.6-github-distribution.md) — read it
first. This plan argues from its decisions and refers to them as D1–D11.

## Global Constraints

- `export CGO_ENABLED := 0` is load-bearing (Makefile). Nothing may introduce cgo.
- **No new module dependencies.** `golang.org/x/sys` moves from indirect to
  direct; nothing else is added. No COM/OLE library — the `.lnk` goes through
  PowerShell, as `Create Bokkie Shortcut.cmd` does today.
- **Do not add fields to `latest.json`.** `ParseManifest` sets
  `DisallowUnknownFields` deliberately (D7 / gotchas).
- **Do not rename `bokkie-win-amd64.exe` in `dist/` or the manifest.**
  `BokkieSetup.exe` is a *copy* published as an extra release asset. The
  manifest keys artifacts by `Platform`, and `Artifact.Verify` compares bytes, so
  a differently-named copy verifies against the same manifest entry. This avoids
  touching `platforms` in `cmd/bokkie-release/main.go`, `pick-binary.sh`, and
  `Install Bokkie.cmd` at all.
- **`make ci` must stay green on macOS.** `vet-all` runs `go vet` once per GOOS,
  so `//go:build windows` files are type-checked here even though they never run.
- Service name `bokkie`, display name `Bokkie LMS`, default port `8080`, install
  path `%ProgramFiles%\Bokkie\bokkie.exe` — all already defined; never re-spell them.
- Copy is read by a non-technical operator standing at a counter. Match the voice
  of `Install Bokkie.cmd`: say what happened, what is untouched, and what to send
  the developer.
- Windows target is **windows/amd64 only**. Windows 10 is the floor.

## Review Focus

These are implied by the spec and would otherwise be nobody's test. Each line
names the task that now owns it.

1. **A cancelled UAC prompt** must say so and exit non-zero, never loop or report success — Task 2.
2. **A stale `BokkieSetup.exe` in Downloads** (older than the current release) must read as "this file is an older release, download it again", not as tampering — Task 6.
3. **No network, or a hung proxy**, must time out and fall into D7's asymmetry rather than blocking the install forever — Task 6.
4. **Running setup from `%ProgramFiles%\Bokkie\bokkie.exe` itself** must not try to copy a file over itself — Task 3.
5. **Uninstall launched from Add/Remove Programs** arrives with no console and no arguments; it must not fall into guided-setup detection and must not vanish silently — Task 5.

```go
// Package winsetup is the Windows desktop integration a double-clicked bokkie
// needs: deciding it was double-clicked at all, asking for administrator
// rights, putting a shortcut on a desktop, and appearing in Add/Remove
// Programs.
//
// Every decision in it is a pure function in an untagged file, and every
// //go:build windows file is a thin wrapper around one syscall. That split is
// not tidiness: no Windows machine has ever been available to this project, so
// anything holding a judgement must be testable on the developer's Mac.
package winsetup

// LaunchedFromExplorer reports whether this process was started by
// double-clicking it rather than typed at a prompt.
//
// One process attached to the console means the console was created for us —
// Explorer makes a fresh one per process, while cmd.exe shares its own, so a
// binary run from a prompt always sees at least two. Arguments settle the rest:
// anything with a command on it was typed, whatever created the window.
func LaunchedFromExplorer(consoleProcesses, argc int) bool {
	return argc < 2 && consoleProcesses == 1
}
```

- [ ] **Step 3: The menu, which is where the judgement lives**

`cmd/bokkie/setup.go`:

```go
package main

// setupState is what the guided window knows about this machine before it
// offers anything.
type setupState struct {
	Installed        bool
	InstalledVersion string
	ThisVersion      string
	Elevated         bool
}

type setupAction int

const (
	actionInstall setupAction = iota
	actionUpdate
	actionRepair
	actionShortcut
	actionUninstall
	actionQuit
)

// setupChoice is one line of the menu.
type setupChoice struct {
	Action     setupAction
	Label      string
	NeedsAdmin bool
}

// menuFor decides what this machine is offered.
//
// The counter PCs are the reason the shortcut is offered first on a machine
// with nothing installed, and the reason it is marked as needing no
// administrator: most people running this file are standing at a counter PC
// that must never become a second host.
func menuFor(state setupState) []setupChoice {
	if !state.Installed {
		return []setupChoice{
			{actionShortcut, "Put a Bokkie shortcut on this computer's desktop", false},
			{actionInstall, "Install Bokkie on this computer (this makes it the host)", true},
			{actionQuit, "Close", false},
		}
	}

	choices := []setupChoice{}
	if state.ThisVersion != state.InstalledVersion {
		choices = append(choices, setupChoice{actionUpdate,
			"Update Bokkie from " + state.InstalledVersion + " to " + state.ThisVersion, true})
	} else {
		choices = append(choices, setupChoice{actionRepair,
			"Repair this installation (reinstall " + state.InstalledVersion + ")", true})
	}
	return append(choices,
		setupChoice{actionShortcut, "Put a Bokkie shortcut on this computer's desktop", false},
		setupChoice{actionUninstall, "Remove Bokkie from this computer (the data folder is kept)", true},
		setupChoice{actionQuit, "Close", false},
	)
}
```

```go
import "errors"

// ErrElevationCancelled is the UAC prompt being dismissed. It is a sentence
// rather than a failure code because the person who dismissed it is the person
// who will read it.
var ErrElevationCancelled = errors.New("Windows was not given permission to continue, so nothing has been changed on this computer")

// double-clicked, and have no way to know it was already the second attempt.
// Naming the action also means the elevated window does one thing and closes,

func ElevatedArgs(action string) []string {
	return []string{"setup", "--elevated", "--do=" + action}
}
```

`internal/winsetup/elevate_windows.go`:

```go
//go:build windows

package winsetup

import (
	"fmt"
	"strings"
	"syscall"

	"golang.org/x/sys/windows"
)

// Elevate restarts exe with administrator rights and returns as soon as
// Windows has accepted the request.
//
// It does not wait for the child: the parent's console closes while the child's
// opens, and a parent that lingered would leave two windows, one of them behind
// the other, both looking like the install.
func Elevate(exe string, args []string) error {
	verb, _ := syscall.UTF16PtrFromString("runas")
	file, err := syscall.UTF16PtrFromString(exe)
	if err != nil {
		return err
	}
	params, err := syscall.UTF16PtrFromString(strings.Join(args, " "))
	if err != nil {
		return err
	}

	err = windows.ShellExecute(0, verb, file, params, nil, windows.SW_NORMAL)
	switch err {
	case nil:
		return nil
	case windows.ERROR_CANCELLED:
		return ErrElevationCancelled
	default:
		return fmt.Errorf("ask Windows for administrator rights: %w", err)
	}
}

// IsElevated reports whether this process is already running as an
// administrator.
func IsElevated() bool {
	var sid *windows.SID
	err := windows.AllocateAndInitializeSid(
		&windows.SECURITY_NT_AUTHORITY, 2,
		windows.SECURITY_BUILTIN_DOMAIN_RID,
		windows.DOMAIN_ALIAS_RID_ADMINS,
		0, 0, 0, 0, 0, 0, &sid)
	if err != nil {
		return false
	}
	defer windows.FreeSid(sid)

	member, err := windows.Token(0).IsMember(sid)
	return err == nil && member
}
```

```go
package winsetup

import (
	"bufio"
	"errors"
	"fmt"
	"io"
)

// PressEnterToClose holds the window open.
//
// Without it a double-click is a console that flashes and vanishes, taking the
// only copy of what went wrong with it — which is the open item step 2.5 named
// "the operator's first inch".
func PressEnterToClose(w io.Writer, r io.Reader) {
	fmt.Fprint(w, "\nPress Enter to close this window.")
	bufio.NewReader(r).ReadString('\n')
}

// The success lines, one per thing this window can do. They are here rather
// than at the call sites so the voice stays one voice.
const (
	DoneInstalled = "Bokkie is installed and starts with this computer.\n\n" +
		"Open this address on any computer or phone at the station:\n" +
		"    http://bokkie.local:8080"
	DoneUpdated = "Bokkie has been updated. The database was backed up first.\n\n" +
		"Open http://bokkie.local:8080 and check the version on the home page."
	DoneShortcut = "A \"Bokkie\" shortcut is now on this computer's desktop.\n\n" +
		"If opening it says the page cannot be reached, the host computer is\n" +
		"switched off, or it is not on this network."
	DoneRemoved = "Bokkie has been removed from this computer.\n\n" +
		"The data folder and every backup in it have been left exactly where\n" +
		"they were. Nothing has been deleted."
)

// ExitMessage is what the window says last.
//
// A cancelled UAC prompt is not a fault and must not read like one; anything
// else gets the words Install Bokkie.cmd uses, because what the person does
// next is the same either way.
//
// done is the caller's success line, because this window does four different
// things and only one of them installs anything. Telling somebody who asked for
// a desktop shortcut that Bokkie now starts with this computer would be a lie
// about the most consequential thing the file can do.
func ExitMessage(err error, done string) string {
	switch {
	case err == nil:
		return done
	case errors.Is(err, ErrElevationCancelled):
		return err.Error()
	default:
		return "This did not finish. Nothing has been removed and the old\n" +
			"system, if there was one, is untouched.\n\n" +
			"Send the developer everything printed above.\n\n" +
			err.Error()
	}
}
```

```go
package main

import (
	"flag"
	"fmt"
	"os"

	"github.com/Dannjann/bokkie-lms/internal/winsetup"

// runGuidedSetup is the window a double-click opens.
//
// It runs twice per install: once unelevated, to show the menu and find out
// what is wanted, and once as administrator with --do naming the answer. The
// parts that need no administrator — the desktop shortcut — are done in the
// first pass, before any prompt is raised.
func runGuidedSetup(args []string) error {
	fs := flag.NewFlagSet("setup", flag.ExitOnError)
	elevated := fs.Bool("elevated", false, "this process was started by the unelevated window")
	do := fs.String("do", "", "the action chosen in the unelevated window")
	if err := fs.Parse(args); err != nil {
		return err
	}

	done, err := guided(*elevated, *do)

	// handedOff is the one case that must stay silent: this window raised a UAC
	// prompt and the elevated copy now owns the job. Two windows holding for
	// Enter, one behind the other, is how an install looks hung.
	if errors.Is(err, errHandedOff) {
		return nil
	}

	fmt.Println()
	fmt.Println(winsetup.ExitMessage(err, done))
	winsetup.PressEnterToClose(os.Stdout, os.Stdin)
	return err
}

// errHandedOff means the work is now the elevated window's, and this one should
// close without claiming anything happened.
var errHandedOff = errors.New("handed off to the administrator window")
```

- [ ] **Step 2: The state the menu is built from**

In `cmd/bokkie/setup.go`:

```go
// describeInstallation works out what this machine already has.
//
// The serving version is preferred over the file on disk because it is the one
// answering on the port — a binary sitting at the install path that is not
// running is a failed update, not an installation. Falling back to "installed
// but not answering" keeps the repair offer available in exactly that case.
func describeInstallation(exePath, installedPath, serving string, servingErr error) setupState {
	state := setupState{
		ThisVersion: buildinfo.Version,
		Elevated:    winsetup.IsElevated(),
		// Review Focus 4: the person may have double-clicked the installed
		// copy in Program Files rather than the download.
		RunningFromInstallPath: sameFile(exePath, installedPath),
	}

	switch {
	case servingErr == nil && serving != "":
		state.Installed, state.InstalledVersion = true, serving
```

```go
package winsetup

import "fmt"

// DefaultAddress is the host as every counter PC reaches it.
const DefaultAddress = "http://bokkie.local:8080"

// ShortcutScript writes a .lnk through WScript.Shell.
//
// PowerShell rather than COM from Go: it is the same call Create Bokkie
// Shortcut.cmd has always made, it needs no new dependency, and the one thing
// worse than shelling out here would be a cgo-free project growing an OLE
// binding for a single file write.
//
// Edge is launched with --app so staff get something that looks like a desktop
// program rather than a web page they might navigate away from.
func ShortcutScript(edge, address, lnk string) string {
	return fmt.Sprintf(
		`$s = (New-Object -ComObject WScript.Shell).CreateShortcut(%s); `+
			`$s.TargetPath = %s; $s.Arguments = %s; `+
			`$s.Description = 'TLS Palay and Corn lending system'; $s.Save()`,
		quote(lnk), quote(edge), quote("--app="+address))
}

// quote makes a PowerShell single-quoted string. A path with an apostrophe in
// it is rare and a path the user typed is not, so doubling is not optional.
func quote(s string) string {
	out := make([]rune, 0, len(s)+2)
	out = append(out, '\'')
	for _, r := range s {
		if r == '\'' {
			out = append(out, '\'')
		}
		out = append(out, r)
	}
	return string(append(out, '\''))
}
```

```go
//go:build windows

package winsetup

import (
	"fmt"
	"os"
	"os/exec"
	"path/filepath"

	"golang.org/x/sys/windows"
)

// FindEdge looks where Edge actually is. The 32-bit location is checked first
// because that is where it lives on a 64-bit Windows, which is every machine
// this will meet.
func FindEdge() (string, error) {
	for _, base := range []string{os.Getenv("ProgramFiles(x86)"), os.Getenv("ProgramFiles")} {
		if base == "" {
			continue
		}
		path := filepath.Join(base, "Microsoft", "Edge", "Application", "msedge.exe")
		if _, err := os.Stat(path); err == nil {
			return path, nil
		}
	}
	return "", fmt.Errorf("could not find Microsoft Edge in the usual place; send the developer this message")
}

// CreateDesktopShortcut puts a Bokkie shortcut on the desktop of whoever is
// running this, and returns where it put it.
//
// The desktop comes from the known folder rather than %USERPROFILE%\Desktop:
// a machine with OneDrive redirecting the desktop has the second one, and the
// shortcut would land somewhere the person is not looking.
func CreateDesktopShortcut(address string) (string, error) {
	edge, err := FindEdge()
	if err != nil {
		return "", err
	}
	desktop, err := windows.KnownFolderPath(windows.FOLDERID_Desktop, 0)
	if err != nil {
		return "", fmt.Errorf("find this computer's desktop: %w", err)
	}

	lnk := filepath.Join(desktop, "Bokkie.lnk")
	cmd := exec.Command("powershell", "-NoProfile", "-ExecutionPolicy", "Bypass",
		"-Command", ShortcutScript(edge, address, lnk))
	if out, err := cmd.CombinedOutput(); err != nil {
		return "", fmt.Errorf("create the shortcut: %w: %s", err, out)
	}
	return lnk, nil
}
```

```go
func selfCheckOutcome(installed, verified bool, failure error) (proceed bool, message string) {
```

- [ ] **Step 1: Copy the friendly name into the release folder**

In `Makefile`, extend `release`:

```make
# BokkieSetup.exe is a copy of the Windows binary, not a different build. The

# folder, pick-binary.sh and the .cmd files need no change at all.
```

- [ ] **Step 2: `make publish`**

```make
# Publishing is local because signing is local: the private release key never
# goes to GitHub, and a repository secret is still a copy of the one key whose
# loss locks every installed host out of updates forever. See 02.6 D10.
#
# The release is created as a draft. The windows-latest check runs against it,
# and publishing is a human click once that is green.
publish:
	@sh scripts/publish.sh
```

`scripts/publish.sh` must: refuse unless `git describe --tags --exact-match`
succeeds; refuse unless `dist/latest.json.sig` exists and is newer than
`dist/bokkie-win-amd64.exe`; then
`gh release create "$TAG" --draft --title "Bokkie $TAG" --notes-file …` with
`dist/BokkieSetup.exe dist/bokkie-* dist/latest.json dist/latest.json.sig` and
the `.cmd`/`.command` wrappers attached.

- [ ] **Step 3: Verify and commit**

```bash
sh -n scripts/publish.sh
git add Makefile scripts/publish.sh
git commit -m "build: publish a draft release, with the key staying on this machine"
```

Expected without a tag: `make release` refuses, naming the `git tag` command.

## The gate

This step is not finished when the tasks are. It is finished when, on the real
Windows 10 machine at the station:

1. The page is opened in Edge, the button clicked, the warning passed, and the
   file run — by somebody who was not told how.
2. The service survives a reboot with nobody logged in.
3. `http://bokkie.local:8080` answers from a second machine and from a phone.
4. A counter PC gets its shortcut from the same file, without an admin password.
5. A second, newer `BokkieSetup.exe` updates the station, and a tampered one is
   refused.
6. Bokkie appears in Add/Remove Programs, and removing it leaves `bokkie.db`
   where it was.

Points 2 and 3 are Step 1's outstanding drill, which this step finally has the
hardware to run.
